🔹 df.describe() e df.describe().T
df.describe()

É um método do Pandas que gera estatísticas descritivas apenas para colunas numéricas (por padrão).

Ele retorna:

count → número de valores não nulos (quantos registros válidos).

mean → média.

std → desvio padrão (o quanto os valores variam em torno da média).

min → menor valor.

25%, 50%, 75% → quartis (valores que dividem o conjunto em 4 partes).

50% é a mediana.

max → maior valor.

Exemplo da coluna House_Price no seu dataset:

mean ≈ 618 mil → preço médio.

min ≈ 40 mil → menor preço.

max ≈ 1.1 milhão → maior preço.

std ≈ 253 mil → preços bem dispersos.

df.describe().T

O .T significa transpose (transposição de matriz).

Ele inverte linhas e colunas:

Em df.describe(), as estatísticas (mean, min, max) aparecem como linhas.

Em df.describe().T, essas estatísticas viram colunas, e cada variável (coluna do dataset) fica organizada em linhas.

👉 É só uma questão de formato visual — fica mais legível para datasets com muitas colunas.

🔹 Parte 1 — df_clean
df_clean = df.copy()

O df.copy() cria uma cópia independente do df.

Isso evita que a gente altere o dataset original sem querer.

Assim, se algo der errado no tratamento, ainda temos o df intacto.

👉 Resumo: df_clean = versão “limpa” do dataset, que a gente vai mexer.
--------------------------------------------------------------------------------------------------------------------------------------------------
🔹 Parte 2 — Quartis e IQR
Q1 = df_clean['House_Price'].quantile(0.25)
Q3 = df_clean['House_Price'].quantile(0.75)
IQR = Q3 - Q1

Q1 (1º quartil, 25%) → valor abaixo do qual estão 25% dos dados.

Q3 (3º quartil, 75%) → valor abaixo do qual estão 75% dos dados.

IQR (Interquartile Range) = Q3 – Q1 → intervalo entre 25% e 75% dos valores.

👉 Esse intervalo mostra onde está a “maioria” dos dados, ignorando extremos.
--------------------------------------------------------------------------------------------------------------------------------------------------
🔹 Parte 3 — Limites para outliers
limite_inferior = Q1 - 1.5 * IQR
limite_superior = Q3 + 1.5 * IQR

A regra clássica de estatística é:

Valores abaixo de Q1 – 1.5×IQR → considerados outliers baixos.

Valores acima de Q3 + 1.5×IQR → considerados outliers altos.

👉 Assim definimos a faixa “aceitável” para os preços de casas.
--------------------------------------------------------------------------------------------------------------------------------------------------
🔹 Parte 4 — Filtragem dos dados
df_clean = df_clean[(df_clean['House_Price'] >= limite_inferior) &
                    (df_clean['House_Price'] <= limite_superior)]

Mantém só as linhas dentro da faixa aceitável.

Se houvesse preços muito estranhos (ex.: uma casa por 1 real ou 50 milhões), seriam removidos.

👉 No seu caso, como o dataset é sintético e bem construído, nenhum dado foi removido (por isso Formato antes e Formato depois são iguais).

🔹 Parte 5 — StandardScaler (nova biblioteca)
from sklearn.preprocessing import StandardScaler


Isso vem da biblioteca scikit-learn (sklearn) → a principal para machine learning no Python.

O StandardScaler serve para padronizar os dados numéricos.

scaler = StandardScaler()
features_scaled = scaler.fit_transform(features)


fit_transform() → primeiro calcula a média e desvio padrão de cada coluna, depois aplica a transformação.

Cada variável vira uma escala com:

média = 0

desvio padrão = 1

👉 Isso é útil porque alguns modelos (ex.: Regressão Linear, Redes Neurais, SVM) funcionam melhor quando todas as variáveis estão na mesma escala.
Exemplo:

Square_Footage → milhares (ex.: 2000, 3000).

Num_Bedrooms → só até 5.
Se não escalarmos, o modelo dá mais importância para variáveis “grandes”.

🔹 O que é X e y?

X (features/atributos) → todas as colunas usadas para prever algo.
Ex.: Square_Footage, Num_Bedrooms, Lot_Size, etc.

y (target/variável alvo) → o que queremos prever.
Ex.: House_Price (preço da casa).

👉 Resumindo:

X = entrada (características)

y = saída (resposta que queremos prever)
