🔹 Diferença para outros modelos de regressão

Regressão Linear

Simples, rápida e fácil de interpretar.

Assume que a relação entre X e y é linear.

Exemplo: quanto maior a metragem (Square_Footage), maior o preço → linha reta.

Árvore de Decisão Regressora

Divide os dados em “ramos” (se o número de quartos > 3, vá para a direita, senão para a esquerda).

Não assume linearidade.

Funciona bem em dados mais complexos, mas pode superajustar (overfitting).

Random Forest / Gradient Boosting

Conjuntos de várias árvores → mais robusto, maior precisão.

Mais pesados, menos interpretáveis.

📦 Bibliotecas usadas

sklearn.linear_model.LinearRegression

Classe que cria o modelo de Regressão Linear.

sklearn.model_selection.train_test_split

Função para dividir os dados em treino (para aprender) e teste (para avaliar).

sklearn.metrics.mean_squared_error

Mede o erro quadrático médio → quanto menor, melhor.

sklearn.metrics.r2_score

Mede o R², que mostra quanto o modelo explica dos dados (varia de 0 a 1).

📜 Código linha por linha
X_train, X_test, y_train, y_test = train_test_split(features_scaled, target, test_size=0.2, random_state=42)


Divide os dados em treino e teste.

test_size=0.2 → 20% vai para teste, 80% para treino.

random_state=42 → garante que a divisão seja sempre a mesma (reprodutibilidade).

modelo_lr = LinearRegression()


Cria um modelo de Regressão Linear vazio (sem estar treinado ainda).

modelo_lr vai aprender a relação entre X (features) e y (target).

modelo_lr.fit(X_train, y_train)


Treina o modelo: o algoritmo calcula os coeficientes (os “pesos” de cada variável) que melhor se ajustam aos dados.

y_pred = modelo_lr.predict(X_test)


Faz previsões no conjunto de teste → o modelo usa o que aprendeu para prever preços de casas que ele nunca viu.

mse = mean_squared_error(y_test, y_pred)

# diferença entre valores reais e previstos

🐍 Código do R² manual
# valores reais e previstos
y_real = y_test
y_previsto = y_pred

# média dos valores reais
y_media = y_real.mean()

# soma dos erros ao quadrado (SSE)
sse = ((y_real - y_previsto) ** 2).sum()

# soma total ao quadrado (SST)
sst = ((y_real - y_media) ** 2).sum()

# cálculo do R²
r2_manual = 1 - (sse / sst)

print("R² calculado manualmente:", r2_manual)


🔹 Esse resultado deve ser idêntico ao r2_score.

📌 Modelos de Regressão usados
1. Regressão Linear

📖 O modelo mais simples e clássico.

Ele tenta ajustar uma reta (ou plano, ou hiperplano) que melhor explica a relação entre as variáveis (X → preço).

Funciona muito bem quando a relação é linear.

Resultado no seu caso:

R² = 0.9984 → o modelo explica 99,84% da variação do preço.

MSE ≈ 101 milhões → erro médio ainda baixo considerando os preços na casa dos milhões.

2. Árvore de Decisão (DecisionTreeRegressor)

📖 Funciona como uma série de perguntas “se-então” (if-else).
Ex:

"O tamanho da casa é maior que 3000 pés²?"

"Se sim → segue para a direita, se não → vai para a esquerda."

Muito flexível, mas pode decorar os dados de treino (overfitting), perdendo generalização.

Resultado no seu caso:

R² = 0.9850 → já é bom, mas menor que a regressão linear.

MSE ≈ 966 milhões → erro bem maior → a árvore não conseguiu generalizar tão bem aqui.

3. Random Forest (RandomForestRegressor)

📖 É um conjunto de várias Árvores de Decisão treinadas em subconjuntos diferentes dos dados.

O resultado final é a média das previsões de todas as árvores.

Isso reduz o risco de overfitting e melhora a precisão.

Resultado no seu caso:

R² = 0.9938 → excelente, quase tão bom quanto a regressão linear.

MSE ≈ 396 milhões → erro bem menor que a árvore isolada, mas maior que a regressão linear.

📊 Interpretação Geral

Melhor modelo nesse dataset → Regressão Linear

Tem maior R² (0.9984) e menor MSE (101M).

Faz sentido: os dados parecem ter uma relação quase perfeitamente linear entre atributos e preço (ex: o scatterplot que você fez mostrou isso).

Árvore de Decisão → ficou pior, porque tentou criar cortes rígidos nos dados.

Random Forest → melhorou em relação à árvore, mas ainda não bateu a regressão linear (provavelmente porque os dados já são lineares, então o modelo simples funciona melhor).
